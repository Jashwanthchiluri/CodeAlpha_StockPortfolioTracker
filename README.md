Stock Portfolio Tracker

Project Description

A simple Python application that calculates the total investment value of stocks using predefined stock prices.

Features

- Displays available stocks and prices.
- Accepts stock names and quantities from the user.
- Calculates individual stock investment values.
- Calculates total portfolio investment.
- Saves the portfolio summary to a text file.
- Handles invalid user input.

Technologies Used

- Python
- Dictionaries
- Loops
- Conditional Statements
- Exception Handling
- File Handling

How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Run the following command in the terminal:

python stock_portfolio.py
